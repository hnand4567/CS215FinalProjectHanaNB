# Spotify Audio Features & Song Popularity Analysis

## Project Overview
This project analyzes a large dataset of Spotify songs to explore what makes music popular. Using audio features such as danceability, energy, tempo, and valence, the analysis investigates patterns in song popularity and musical style.

The project uses Python in a Google Colab notebook along with machine learning techniques such as K-Means clustering and Principal Component Analysis (PCA) to identify and visualize structure in the data.
