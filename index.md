# Spotify Audio Features & Song Popularity Analysis

## Project Overview

This project explores how audio features relate to song popularity using a Kaggle dataset.

Using this dataset, I analyzed:
- Relationships between danceability, energy, and popularity
- Trends in audio features across songs
- Which features most strongly predict popularity

---

## Research Questions

1. What audio features are most associated with song popularity?
2. How do features like energy and danceability relate?
3. Can we predict popularity from audio features?

---

## Methods

I used Python and pandas in Google Colab to:
- clean and reprocess the dataset
- explore correlations between variables
- create visualizations of trends
